## Two ways to work, one binary

<Tabs syncKey="interface">
<TabItem label="The REPL">
For quick questions and muscle memory. Type SQL, get a table. Completion knows your schema,
statements are highlighted as you type, and `\d`-style commands work on every database.

```sh
quarry postgres://me@localhost/app
```
</TabItem>
<TabItem label="The TUI">
For exploring. A schema explorer, tabbed editors, a results grid built for large results, a table
browser with staged edits, an explain-plan viewer and a command palette.

```sh
quarry --tui mysql://root@127.0.0.1/shop
```
</TabItem>
<TabItem label="Scripts">
For pipelines. Run SQL from a flag, a file or stdin, and get CSV, JSON, TSV or Markdown out.

```sh
quarry app.db -e "select * from users" -F csv > users.csv
```
</TabItem>
</Tabs>

## What you get

<CardGrid>
	<Card title="Completion that reads your schema" icon="magnifier">
		Tables after `FROM`, columns after `SELECT` (aliases included), `JOIN … ON` suggested from
		foreign keys, `SELECT *` expansion, functions, types and file paths. Fuzzy, so `ui` finds
		`user_id`.
	</Card>
	<Card title="Three databases, one tool" icon="database">
		PostgreSQL, MySQL / MariaDB and SQLite, with the psql-style `\d` family translated for each.
		TLS is built in and SQLite is bundled, so there is nothing else to install.
	</Card>
	<Card title="Safe by default" icon="padlock">
		`DROP`, `TRUNCATE` and `DELETE` without a `WHERE` ask first. `--readonly` blocks writes in
		quarry and at the server. Statements that set passwords stay out of history.
	</Card>
	<Card title="Ask in plain English" icon="comment">
		`\llm top 10 customers by revenue` writes SQL for your schema and puts it in front of you to
		review. Use an API key, Ollama, or the Claude Code or Codex CLI you already have.
	</Card>
	<Card title="Built for big results" icon="rocket">
		Rows stream as they arrive. `Ctrl-C` cancels at the server. The TUI grid is virtualised, and
		the REPL asks before printing more than you meant to.
	</Card>
	<Card title="Looks the way you like" icon="star">
		27 built-in themes shared by the REPL and the TUI, including Tokyo Night, Catppuccin, Gruvbox,
		Dracula and Nord, plus your own TOML themes and any base16 or base24 scheme.
	</Card>
</CardGrid>

## Up and running in a minute

<Steps>

1. From a checkout of the repository, build and install quarry (you need [Rust](https://rustup.rs)):

   ```sh
   cargo install --path .
   ```

2. Open any database:

   ```sh
   quarry data.db                          # a SQLite file
   quarry postgres://me@localhost/app      # PostgreSQL
   quarry mysql://root@127.0.0.1/shop      # MySQL or MariaDB
   ```

3. Type `\?` for every command, or `\tui` to switch to the full-screen interface.

</Steps>
